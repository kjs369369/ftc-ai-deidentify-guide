원본(신고인·진술인 실명 포함)은 내 PC에서만, AI에는 ‘비식별 사본’만 올린다.

신고·민원 접수대장 · 진술조서 요약표 · 거래내역 및 입찰 명세 · 하도급대금 지급현황 · 가맹점·대리점 실태조사 응답 · 소비자 피해 접수 명단

📋 아래 글을 그대로 복사해 Claude에 붙여넣기
공정거래 사건 자료(엑셀·CSV)의 개인정보와 사업자 식별정보를 '내 컴퓨터 안에서만' 지우는 HTML 웹앱을 한 개 파일로 만들어줘. 조건: 1) 파일을 인터넷으로 보내지 말고 브라우저 안에서만 처리 2) 신고인·진술인 이름은 A001, 사업자명은 갑제1사·을제2사처럼 코드로 치환 3) 주민등록번호·사업자등록번호·연락처·주소·이메일·계좌번호는 삭제 4) 업종·지역·거래금액 구간은 그대로 두되 선택하면 삭제도 가능 5) 치환 대조표(원본 ↔ 코드)를 별도 파일로 따로 저장하는 버튼 6) 결과를 엑셀(.xlsx)과 CSV로 저장하는 버튼 7) '샘플 데이터로 체험' 버튼 포함 8) 40~60대도 쉽게 쓰도록 큰 글씨·한국어로
💡 결과가 마음에 안 들면 “글씨 더 크게”, “계좌번호 뒤 4자리는 남겨줘”처럼 이어서 말하면 고쳐줍니다.
경로 A

아티팩트로 만들기 (제일 쉬움)

1
claude.ai 접속 → 새 대화
2
위 프롬프트 붙여넣기 → 전송
3
오른쪽에 앱이 생기면 미리보기로 확인
4
앱 오른쪽 위 다운로드 → HTML 저장
5
내 컴퓨터에서 그 파일 더블클릭 → 실행
6
사건 자료 올리고 ‘비식별 실행’ → 사본 저장
경로 B

코워크 폴더로 정리하기

1
Claude 데스크톱 앱 → 코워크 탭
2
사건별 작업 폴더 지정
3
위 프롬프트로 앱을 만들어 폴더에 저장
4
그 HTML을 내 컴퓨터에서 실행해 비식별
5
비식별 사본은 작업 폴더, 대조표는 별도 보안 폴더
✓
원본은 모델이 직접 읽지 않게 — 실행은 내 PC에서
