나만의 업무자료 비식별 앱 만들기

Claude에게 부탁해서, 내 컴퓨터에서만 실행합니다. 설치는 없습니다.

딱 하나만 기억하세요.
원본(고객·직원 실명)은 내 PC에서만, AI에는 비식별 사본만 올린다.

회사 보안 규정이 우선이며, 원본은 내 PC에서만 다룬다. 반출이 막힌 파일은 연습에 쓰지 말고, 샘플로 먼저 해 보세요.

완성품 예시

강사가 위 조건으로 미리 만들어 둔 화면입니다. 여러분이 Claude로 만든 앱과 모습이 달라도 됩니다.

완성품 예시 열어보기

이런 자료에 씁니다

  • 거래처·고객 명단
  • 견적서·발주·납품 내역
  • 고객 클레임/AS 접수 대장
  • 직원·협력사 인력 명단
  • 현장 안전점검표
  • 설문 응답
아래 글을 그대로 복사해 Claude에 붙여 넣기
회사 업무용 엑셀·CSV에서 개인정보와 업체 식별정보를 지우는 웹앱을 HTML 파일 한 개로 만들어 주세요.
만든 뒤 아티팩트 미리보기로 바로 보여 주세요. 저장한 HTML을 더블클릭해 브라우저로 열어도, 인터넷과 Claude 없이 그대로 동작해야 합니다.

조건:
1) 파일 내용은 인터넷으로 보내지 말고, 브라우저 안에서만 처리합니다. 외부 서버로 업로드하지 않습니다.
2) 사람 이름(고객, 직원, 담당자)은 P001, P002처럼 코드로 바꿉니다. 회사·거래처·협력사 이름은 거래처A, 협력사B처럼 코드로 바꿉니다.
3) 주민등록번호, 사업자등록번호, 연락처, 주소, 이메일, 계좌번호는 삭제합니다.
4) 업종, 지역(시·군), 품목, 금액 구간, 날짜는 기본으로 남기고, 화면에서 선택하면 그 항목도 지울 수 있게 합니다.
5) 치환 대조표(원본 ↔ 코드)를 별도 파일로 받는 버튼을 만듭니다.
6) 결과를 엑셀(.xlsx)과 CSV로 받는 버튼을 만듭니다.
7) '샘플 데이터로 체험' 버튼을 넣습니다. 샘플에는 거래처 명단, 견적·발주·납품, 클레임/AS, 인력 명단, 안전점검, 설문 같은 회사 업무 예시가 있으면 좋습니다.
8) 40~60대도 바로 쓸 수 있게 큰 글씨, 한국어, 큼직한 버튼으로 만듭니다.

같은 대화에 이어서 말하면 고쳐 줍니다. 예: “글씨와 버튼을 더 크게”, “금액은 구간으로 바꿔 주세요”.

결과가 다르면 이어서 말합니다

  1. 미리보기가 없으면 아티팩트 미리보기로 보여 주세요.
  2. 코드만 보이면 이 앱을 HTML 파일 한 개로 주세요. 메모장에 저장해 브라우저로 열겠습니다.
  3. 글씨가 작으면 글씨와 버튼을 더 크게 해 주세요.
  4. 예시가 모자라면 샘플에 견적, 납품, 클레임 접수 행을 넣어 주세요.
  5. 금액이 그대로면 금액은 100만 원 미만처럼 구간으로 바꿔 주세요.
  6. 주소가 걱정되면 주소는 지우고, 시·군만 남겨 주세요.
기본 경로

웹 Claude로 만들기

무료 계정으로 됩니다. Chrome만 있으면 되고, 설치는 없습니다.

  1. claude.ai를 Chrome에서 열고 로그인합니다.
  2. 새 대화를 열고 위 글을 붙여 넣어 전송합니다.
  3. 옆에 앱 화면(아티팩트)이 생기면 미리보기로 확인합니다.
  4. 아티팩트 화면의 다운로드/내보내기 메뉴에서 HTML로 저장합니다.
  5. 저장한 파일을 더블클릭해 내 브라우저에서 엽니다.
  6. 샘플 데이터로 체험한 뒤, 내 파일을 올려 사본을 저장합니다.

메뉴 이름은 화면마다 다를 수 있습니다. .html 파일이 받아지면 됩니다. 코드만 보이면 위의 문장으로 HTML 한 개를 받아, 메모장에 붙여 비식별.html로 저장하세요. Windows 메모장은 파일 형식을 ‘모든 파일’로 고릅니다. 미리보기 창이 아예 없으면 설정(Settings) → 기능(Capabilities)에서 ‘파일 만들기·편집(Create and edit files)’이 켜져 있는지 확인합니다.

강사 시연용

코워크로 폴더 정리

유료 플랜 · 데스크톱 앱 설치 필요 (강사 시연용)

수업의 기본 경로는 ‘웹 Claude로 만들기’입니다.

  1. Claude 데스크톱 앱에서 코워크(Cowork) 탭을 엽니다.
  2. 오늘 쓸 작업 폴더를 지정합니다.
  3. 같은 글로 앱을 만들어 그 폴더에 HTML로 저장합니다.
  4. 저장된 HTML을 내 컴퓨터에서 실행합니다.
  5. 비식별 사본은 작업 폴더, 대조표는 다른 폴더에 둡니다.
  6. 원본은 모델이 직접 읽지 않게 하고, 실행은 내 PC에서만 합니다.

항목처리이유
고객·직원·담당자 이름 코드로 바꿈 (P001) 누구인지 몰라도 건수는 셀 수 있습니다.
거래처·협력사 이름 코드로 바꿈 (거래처A, 협력사B) 업체는 구분만 되면 집계할 수 있습니다.
주민등록번호·사업자등록번호 삭제 업무 집계에 필요 없는 식별번호입니다.
연락처·주소·이메일·계좌 삭제 밖으로 나가면 피해가 바로 생깁니다.
업종·지역·품목·금액 구간 남김 (원하면 삭제) 견적, 납품, 클레임, 점검 패턴을 볼 때 필요합니다.
접수일·납품일·점검일 남김 (필요하면 월만) 시기 비교에 필요합니다. 인원이 적으면 월 단위가 안전합니다.

이렇게 되면 성공

  • 사람 이름이 P001, P002…로 바뀌었다.
  • 거래처·협력사 이름이 거래처A, 협력사B…로 바뀌었다.
  • 주민등록번호, 사업자등록번호, 연락처, 주소, 이메일, 계좌가 빠졌다.
  • 치환 대조표는 사본과 다른 폴더에 따로 두었다.
  • AI에는 그 사본만 올린다. 원본과 대조표는 올리지 않는다.
