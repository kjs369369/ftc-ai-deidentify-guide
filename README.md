# 따라하기: 나만의 ‘사건자료 비식별 앱’ 만들기

공정거래위원회 실전 AI 클래스(심화) 실습 안내 페이지입니다.

**🔗 배포 주소:** https://kjs369369.github.io/ftc-ai-deidentify-guide/

## 핵심 원칙

> 원본(신고인·진술인 실명 포함)은 내 PC에서만, AI에는 ‘비식별 사본’만 올린다.

## 담긴 내용

- Claude에 그대로 붙여넣는 비식별 앱 제작 프롬프트
- 경로 A: 아티팩트로 만들기 / 경로 B: 코워크 폴더로 정리하기
- 무엇을 지우고 무엇을 남길지 정리한 처리 기준표
- 실습 성공 여부 체크리스트
