# 따라하기: 나만의 업무자료 비식별 앱 만들기

기업 실무에서 쓰는 엑셀·CSV를 **내 컴퓨터 안에서만** 비식별하는 실습 안내 페이지입니다. 설치 없이 무료 웹 Claude(claude.ai)로 따라 합니다.

**배포 주소:** https://kjs369369.github.io/ftc-ai-deidentify-guide/

## 핵심 원칙

원본은 내 PC에서만 다루고, AI에는 비식별 사본만 올립니다. 회사 보안 규정이 우선입니다.

## 이런 자료 예시

거래처·고객 명단, 견적서·발주·납품 내역, 고객 클레임/AS 접수 대장, 직원·협력사 인력 명단, 현장 안전점검표, 설문 응답.

사람 이름은 P001, 업체 이름은 거래처A·협력사B처럼 바꿉니다.

## 담긴 내용

- Claude에 그대로 붙여 넣는 비식별 앱 제작 프롬프트
- 기본 경로: 무료 웹 Claude 아티팩트 (브라우저만, 설치 없음)
- 강사 시연: 코워크 폴더 (유료 플랜·데스크톱 앱 설치 필요)
- 지울 항목과 남길 항목
- 성공 체크리스트
